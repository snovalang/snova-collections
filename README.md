# Snova Collections (`Snova.Std.Collections`)

Fundamental data structure collections in pure Snovalang.

## Features
- `List` (dynamic resizable array list)
- `Map` (associative key-value dictionary)
- `Set` (unique element collection)
- `Queue` (FIFO queue)
